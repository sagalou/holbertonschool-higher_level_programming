# JavaScript - DOM Manipulation

## Description

This project focuses on understanding and manipulating the DOM (Document Object Model) with JavaScript, directly in the browser. It covers selecting HTML elements, modifying their style and content, listening to user events, and making network requests using `XMLHttpRequest` and the `Fetch` API.

## Learning Objectives

At the end of this project, I am able to explain, without the help of Google:

- How to select HTML elements in JavaScript
- What are the differences between ID, class and tag name selectors
- How to modify an HTML element style
- How to get and update an HTML element content
- How to modify the DOM
- How to make a request with `XmlHTTPRequest`
- How to make a request with the `Fetch` API
- How to listen/bind to DOM events
- How to listen/bind to user events

## Requirements

- All files are interpreted in Chrome browser (version 57.0 or later)
- All files end with a new line
- Code is `semistandard` compliant
- The use of `var` is not allowed (`const` and `let` only)
- The HTML must never reload to perform an action (DOM manipulation, updating values, fetching data...)

## Files

| File | Description |
|---|---|
| `0-script.js` | Updates the text color of the `header` element to red |
| `1-script.js` | Updates the text color of the `header` element to red on button click |
| `2-script.js` | Adds the `red` class to the `header` element on button click |

| `4-script.js` | Adds a `<li>` element to a list on button click |
| `5-script.js` | Updates the text of an element on button click |
| `6-script.js` | Fetches and displays a Star Wars character using the Star Wars API |
| `7-script.js` | Fetches and displays the list of Star Wars movies using the Star Wars API |
| `8-script.js` | Displays "Hello" on button click, and "Goodbye" on a second click |
